# Описание страницы "Заказы"

## Введение

Страница "Заказы" является центральным элементом системы управления CoffeCRM. Она предоставляет пользователям комплексный инструмент для просмотра, создания, редактирования и отслеживания всех заказов, поступающих в кофейню. Данная страница спроектирована таким образом, чтобы обеспечить максимальную эффективность и удобство для персонала, начиная от бариста и заканчивая менеджерами и владельцами бизнеса.

Основная цель страницы — предоставить полный обзор операционной деятельности, связанной с заказами, и обеспечить быстрый доступ ко всей необходимой информации. Интуитивно понятный интерфейс и логичная структура позволяют пользователям с минимальными усилиями управлять потоком заказов, контролировать их статусы, анализировать данные о продажах и взаимодействовать с информацией о клиентах.

## Структура страницы

Страница "Заказы" состоит из нескольких ключевых блоков, каждый из которых выполняет свою специфическую функцию:

1.  **Заголовок и навигация**: В верхней части страницы расположен заголовок "Заказы" и подзаголовок, кратко описывающий ее назначение. Также здесь находятся кнопки для выполнения основных действий — "Обновить" и "Создать заказ".
2.  **Информационные карточки (KPI)**: Набор из четырех карточек, отображающих ключевые показатели эффективности (KPI) в реальном времени. Эти карточки служат дашбордом для быстрого анализа текущей ситуации.
3.  **Панель фильтров**: Инструмент для поиска и фильтрации заказов по различным критериям, таким как статус или ID заказа.
4.  **Таблица заказов**: Основная часть страницы, где в табличном виде представлены все заказы с их ключевыми атрибутами.
5.  **Пагинация**: Элемент управления для навигации по страницам списка заказов.
6.  **Модальные окна**:
    *   **Форма создания/редактирования заказа (`OrderForm`)**: Появляется при создании нового или редактировании существующего заказа.
    *   **Детали заказа (`OrderDetails`)**: Открывается для просмотра подробной информации о конкретном заказе.

## Подробное описание компонентов

### 1. Заголовок и основные действия

В верхней части страницы находится заголовок **"Заказы"**, который четко идентифицирует текущий раздел системы. Под ним расположен подзаголовок **"Управляйте заказами, отслеживайте статусы и анализируйте продажи"**, который дает пользователю краткое представление о функциональных возможностях страницы.

Справа от заголовка расположены две кнопки:

*   **Кнопка "Обновить"**: Позволяет пользователю вручную обновить список заказов и информационные карточки. Это полезно для получения самых актуальных данных без необходимости перезагружать всю страницу. При нажатии на кнопку отправляется запрос на сервер для повторной загрузки данных.
*   **Кнопка "Создать заказ"**: Открывает модальное окно с формой для создания нового заказа. Эта кнопка является основной точкой входа для регистрации новых продаж или других операций с заказами. Доступ к этой кнопке регулируется системой прав доступа (`usePermissions`), что означает, что только авторизованные пользователи (например, менеджеры или старшие бариста) могут создавать новые заказы.

### 2. Информационные карточки (KPI)

Этот блок состоит из четырех стилизованных карточек, каждая из которых отображает важный показатель:

*   **Всего заказов**: Показывает общее количество заказов в системе, которые соответствуют текущим фильтрам. Этот показатель дает общее представление об объеме операций.
*   **В работе**: Отображает количество заказов, которые в данный момент находятся в статусе "В работе" (`IN_PROGRESS`). Это помогает менеджерам оценить текущую загрузку персонала.
*   **Выполнено**: Показывает количество успешно завершенных заказов (`COMPLETED`). Этот KPI важен для анализа производительности и объема выполненной работы.
*   **Выручка**: Суммирует общую стоимость всех выполненных заказов. Это ключевой финансовый показатель, который позволяет отслеживать доходность.

Каждая карточка имеет свой цветовой акцент, что улучшает визуальное восприятие и позволяет быстро считывать информацию.

### 3. Панель фильтров

Панель фильтров предоставляет пользователям возможность быстро находить нужные заказы в общем списке. Она включает в себя следующие элементы:

*   **Фильтр по статусу**: Выпадающий список, который позволяет отфильтровать заказы по их текущему статусу. Доступные опции:
    *   `Все`
    *   `Новый`
    *   `В работе`
    *   `Готов`
    *   `Выполнен`
    *   `Отменен`
*   **Поиск**: Текстовое поле для поиска по различным атрибутам заказа, таким как ID заказа или имя клиента. Поиск осуществляется динамически по мере ввода текста.

Использование фильтров позволяет значительно сократить время на поиск нужной информации, особенно при большом объеме данных.

### 4. Таблица заказов (`OrderTable`)

Это центральный компонент страницы, представляющий собой таблицу со списком заказов. Каждая строка таблицы соответствует одному заказу и содержит следующую информацию:

*   **№**: Уникальный идентификатор заказа (отображаются первые 8 символов).
*   **Дата**: Дата и время создания заказа.
*   **Филиал**: Название филиала, в котором был создан заказ.
*   **Клиент**: Имя клиента. Если заказ был сделан гостем, отображается "Гость".
*   **Статус**: Текущий статус заказа, отображаемый в виде цветной метки (`Chip`), что позволяет быстро визуально оценить состояние заказа.
*   **Тип**: Тип операции (`EXPENSE` - продажа, `INCOME` - возврат, `WRITE_OFF` - списание).
*   **Движ.**: Количество связанных с заказом транзакций по складу.
*   **Сумма**: Общая стоимость заказа.
*   **Товаров**: Количество позиций в заказе.
*   **Действия**: Иконки для взаимодействия с заказом:
    *   **Просмотр** (иконка "глаз"): Открывает модальное окно `OrderDetails` с подробной информацией о заказе.
    *   **Редактировать** (иконка "карандаш"): Открывает модальное окно `OrderForm` для редактирования выбранного заказа.

Доступ к кнопкам "Просмотр" и "Редактировать" также контролируется системой прав, что предотвращает несанкционированные изменения.

### 5. Пагинация

Под таблицей заказов находится элемент пагинации, который позволяет пользователю перемещаться по страницам списка. Пользователь может выбирать количество строк, отображаемых на одной странице (10, 20, 50, 100), что обеспечивает гибкость при работе с большими объемами данных.

### 6. Модальное окно "Форма заказа" (`OrderForm`)

Это модальное окно используется как для создания, так и для редактирования заказов.

**При создании заказа**:
*   **Филиал**: Выпадающий список для выбора филиала, к которому относится заказ.
*   **ID клиента**: Необязательное поле для привязки заказа к существующему клиенту.
*   **Тип**: Выбор типа операции (Расход, Приход, Списание).
*   **Товары в заказе**:
    *   Пользователь может добавлять одну или несколько позиций в заказ.
    *   Для каждой позиции можно выбрать товар из выпадающего списка, указать количество и цену (цена подставляется автоматически при выборе товара, но может быть изменена вручную).
    *   Итоговая сумма по каждой позиции рассчитывается автоматически.
*   **Итоговая сумма**: Общая стоимость всех товаров в заказе.

**При редактировании заказа**:
*   Все поля, доступные при создании, также доступны для редактирования.
*   Дополнительно появляется поле **"Статус"**, позволяющее изменить текущий статус заказа.
*   Возможность изменять состав заказа, добавляя или удаляя товары, а также изменяя их количество и цену.

### 7. Модальное окно "Детали заказа" (`OrderDetails`)

Это окно предназначено для просмотра подробной информации о заказе в режиме "только для чтения".

*   **Заголовок**: Отображает номер заказа и его текущий статус в виде цветной метки.
*   **Информация о заказе**: Блок с основной информацией: дата создания, филиал, тип, данные клиента (имя, телефон, email).
*   **Сумма заказа**: Карточка с итоговой суммой заказа.
*   **Состав заказа**: Таблица с перечнем всех товаров в заказе, включая их изображение, название, цену, количество и итоговую стоимость по каждой позиции.
*   **Движения по складу**: Если с заказом связаны какие-либо складские операции, они отображаются в отдельной таблице с указанием типа, количества, цены, суммы, даты и причины транзакции.

## Заключение

Страница "Заказы" в CoffeCRM — это мощный и гибкий инструмент, который покрывает все основные потребности бизнеса в управлении заказами. Благодаря продуманной структуре, информативным KPI, удобной фильтрации и детализированным модальным окнам, страница обеспечивает высокую эффективность работы персонала и предоставляет важные данные для анализа и принятия управленческих решений.
