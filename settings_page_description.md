# Описание страницы "Настройки"

Страница "Настройки" является центральным узлом для управления глобальными параметрами системы CoffeCRM. Она спроектирована таким образом, чтобы предоставить администраторам и уполномоченным пользователям интуитивно понятный и структурированный интерфейс для конфигурации различных аспектов работы платформы. Доступ к этой странице и ее отдельным разделам строго регламентируется системой прав, гарантируя, что только авторизованные сотрудники могут вносить критические изменения.

Интерфейс страницы разделен на три логические вкладки, каждая из которых отвечает за свою область настроек:

1.  **Компания**: Управление основной информацией и юридическими реквизитами организации.
2.  **Платежи**: Настройка и управление интеграциями с платежными системами.
3.  **Интеграции**: Конфигурация подключений к внешним сервисам, таким как CRM, аналитика и другие.

## Вкладка "Компания"

Эта вкладка представляет собой исчерпывающую форму для ввода и редактирования всех ключевых данных о компании. Корректное и полное заполнение этих полей имеет решающее значение для правильной работы многих функций системы, включая генерацию документов, взаимодействие с клиентами и соответствие законодательным требованиям.

### Структура формы

Форма логически сгруппирована в несколько секций для удобства восприятия и заполнения.

#### 1. Основная информация
Здесь собраны базовые данные, идентифицирующие компанию в системе и для клиентов.
-   **Название компании**: Основное, публичное название компании, которое будет отображаться в интерфейсе, на витрине и в уведомлениях для клиентов. (например, "Кофейня 'Уют'").
-   **Юридическое название**: Полное официальное наименование организации в соответствии с учредительными документами. Используется для договоров, счетов и других официальных бумаг.
-   **Описание**: Развернутое описание деятельности компании. Этот текст может использоваться на странице "О нас", в маркетинговых материалах или для внутреннего пользования.

#### 2. Реквизиты
Эта секция содержит ключевые юридические и налоговые идентификаторы компании.
-   **ИНН** (Идентификационный номер налогоплательщика): Уникальный код, присваиваемый ФНС.
-   **КПП** (Код причины постановки на учет): Дополняет ИНН для организаций.
-   **ОГРН** (Основной государственный регистрационный номер): Номер записи о создании юридического лица в ЕГРЮЛ.
-   **Юридический адрес**: Официальный адрес регистрации компании.
-   **Фактический адрес**: Адрес, по которому компания реально осуществляет свою деятельность, если он отличается от юридического.

#### 3. Контакты
Информация для связи с компанией.
-   **Телефон**: Основной контактный номер телефона.
-   **Email**: Официальный электронный адрес для корреспонденции.
-   **Сайт**: Адрес веб-сайта компании.

#### 4. Банковские реквизиты
Данные, необходимые для проведения банковских операций и расчетов с контрагентами.
-   **Банк**: Наименование банка, в котором открыт расчетный счет.
-   **Расчетный счет**: Номер основного банковского счета компании.
-   **БИК** (Банковский идентификационный код): Уникальный код банка.
-   **Система налогообложения**: Указание применяемой системы (ОСН, УСН и т.д.).
-   **Директор**: ФИО руководителя организации.
-   **Бухгалтер**: ФИО главного бухгалтера.

### Процесс сохранения
После внесения всех необходимых изменений пользователь нажимает кнопку **"Сохранить"**. Система отправляет обновленные данные на сервер. На время сохранения кнопка становится неактивной и отображает статус "Сохранение...", предотвращая повторные отправки. В случае успешного сохранения, пользователь получает уведомление. Если возникает ошибка (например, из-за проблем с сетью или валидацией на сервере), отображается соответствующее сообщение об ошибке.

## Вкладка "Платежи"

Этот раздел предназначен для управления способами приема онлайн-платежей. Администратор может подключать, настраивать и отключать различные платежные шлюзы, обеспечивая гибкость для клиентов и бизнеса.

### Основные элементы интерфейса

-   **Кнопка "Добавить"**: Инициирует процесс добавления новой платежной системы.
-   **Таблица платежных настроек**: Отображает список уже подключенных интеграций со следующими колонками:
    -   **Провайдер**: Название платежного сервиса (например, YooKassa, Stripe, SberPay).
    -   **Название**: Внутреннее название настройки для удобства идентификации.
    -   **API ключ**: Маскированный ключ для безопасности.
    -   **Статус**: Показывает, активна ли данная настройка (`Активна`/`Неактивна`).
    -   **Режим**: Указывает, работает ли интеграция в боевом (`Продакшн`) или тестовом (`Тест`) режиме.
    -   **Действия**: Иконки для редактирования и удаления соответствующей настройки.

### Процесс добавления и редактирования

При нажатии на кнопку "Добавить" или иконку редактирования открывается модальное окно (диалог) с формой для ввода параметров интеграции:

-   **Провайдер**: Название сервиса.
-   **Название**: Пользовательское имя для этой настройки.
-   **API ключ** и **Секретный ключ**: Ключи доступа, полученные от платежного провайдера. Вводятся как пароли (маскируются).
-   **ID мерчанта** / **ID терминала**: Дополнительные идентификаторы, если они требуются провайдером.
-   **Комиссия (%)**, **Минимальная/Максимальная сумма**: Финансовые параметры для внутреннего учета и ограничений.
-   **Webhook URL**: URL для получения уведомлений от платежной системы о статусе платежей.
-   **Иконка (URL)**: Ссылка на иконку платежной системы для отображения на странице оплаты.
-   **Флаги "Активный провайдер"** и **"Тестовый режим"**: Чекбоксы для быстрого включения/отключения настройки и переключения между тестовой и боевой средой.

Валидация формы проверяет заполнение обязательных полей перед отправкой на сервер.

## Вкладка "Интеграции"

Аналогично вкладке "Платежи", этот раздел позволяет управлять подключениями к различным внешним сервисам, расширяя функциональность CoffeCRM.

### Основные элементы интерфейса

-   **Кнопка "Добавить"**: Открывает форму для новой интеграции.
-   **Таблица интеграций**: Содержит список подключенных сервисов.
    -   **Название**: Имя интеграции, заданное пользователем.
    -   **Тип**: Категория интеграции (CRM-система, Аналитика, СМС-сервис и т.д.).
    -   **Провайдер**: Название конкретного внешнего сервиса (например, amoCRM, Google Analytics).
    -   **Статус**: `Активна` или `Неактивна`.
    -   **Синхронизация**: Отображает статус последней синхронизации данных (`SUCCESS`, `ERROR`, `SYNCING`) и ее время.
    -   **Действия**: Кнопки для запуска синхронизации, редактирования и удаления интеграции.

### Процесс добавления и редактирования

Форма в модальном окне включает:

-   **Название** и **Тип интеграции** (выпадающий список).
-   **Провайдер** и **URL иконки**.
-   **API ключ** и **Секретный ключ** для аутентификации.
-   **URL API** и **Webhook URL** для взаимодействия систем.
-   **Флаги "Активная интеграция"** и **"Тестовый режим"**.

Особое внимание уделяется функции **синхронизации**. При нажатии на соответствующую иконку система инициирует фоновый процесс обмена данными с внешним сервисом (например, загрузка лидов из CRM). Статус процесса отображается в реальном времени, позволяя администратору контролировать целостность данных.
