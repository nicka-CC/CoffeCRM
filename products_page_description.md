# Описание страницы "Товары и меню"

Страница "Товары и меню" является ключевым разделом системы CoffeCRM для управления всем ассортиментом продукции. Здесь пользователи могут централизованно создавать, просматривать, редактировать и организовывать все товарные позиции, от готовых блюд и напитков до отдельных ингредиентов.

## Основной интерфейс: Каталог товаров

Главный экран страницы представляет собой интерактивный каталог, реализованный в виде таблицы со списком всех товаров.

### Функциональные элементы

-   **Заголовок**: "Товары и меню" с подзаголовком "Управляйте ассортиментом, ценами и остатками по филиалам", который кратко описывает назначение раздела.
-   **Фильтр**: Выпадающий список, позволяющий фильтровать отображаемые товары по типу:
    -   **Все**: Показывает все товарные позиции.
    -   **Только готовые**: Отображает только конечные продукты, доступные для продажи.
    -   **Только ингредиенты**: Показывает только составные части, используемые в рецептах.
-   **Кнопка "Добавить товар"**: Открывает модальное окно с формой для создания новой товарной позиции.
-   **Пагинация**: Элементы управления для навигации по страницам списка, если товаров больше, чем может поместиться на одной странице.

### Таблица товаров

Таблица предоставляет сводную информацию о каждом продукте в удобном для восприятия виде.

-   **Колонки таблицы**:
    -   **Фото**: Миниатюра изображения товара.
    -   **Название**: Наименование товара.
    -   **Категория**: Категория, к которой относится товар (например, "Горячие напитки", "Десерты").
    -   **Цена**: Розничная цена продажи.
    -   **Себестоимость**: Расчетная стоимость производства одной единицы товара.
    -   **Складов**: Количество филиалов, на складах которых числится данный товар.
    -   **Статус**: `Активен` (отображается на витрине) или `Скрыт` (недоступен для продажи).
    -   **Действия**: Набор кнопок для взаимодействия с товаром:
        -   **Редактировать** (иконка карандаша): Открывает форму редактирования товара.
        -   **Удалить** (иконка корзины): Удаляет товар из системы после подтверждения.
        -   **Остатки по филиалам** (иконка коробки): Появляется, если товар есть на складах, и раскрывает дополнительную информацию.

-   **Раскрываемая информация об остатках**:
    При нажатии на иконку "Остатки по филиалам" под основной строкой товара появляется вложенная таблица, детализирующая количество данного товара в каждом филиале. Это позволяет быстро оценить распределение остатков по всей сети.

## Форма создания и редактирования товара

При создании нового товара или редактировании существующего открывается многофункциональная форма, сгруппированная по разделам-аккордеонам для удобства навигации.

### 1. Основная информация
-   **Название**: Обязательное поле для наименования товара.
-   **Название на английском**: Опционально, для мультиязычных систем.
-   **Категория**: Выбор категории из выпадающего списка.
-   **Загрузить изображение**: Кнопка для загрузки фотографии товара.
-   **Описание**: Подробное маркетинговое описание продукта.

### 2. Цены и идентификация
-   **Цена**, **Себестоимость**, **Старая цена**: Поля для управления ценообразованием.
-   **Артикул (SKU)**, **Штрихкод**: Уникальные идентификаторы для складского учета и интеграции с кассовым оборудованием.
-   **Единица измерения**: Выбор единицы (шт, кг, л и т.д.).
-   **Порядок сортировки**: Числовое значение для определения позиции товара в списке.

### 3. Физические характеристики
-   **Вес (г)**, **Объем (мл)**: Физические параметры продукта.
-   **Калории**, **Белки (г)**, **Жиры (г)**, **Углеводы (г)**: Пищевая ценность (КБЖУ), важная для информирования клиентов.

### 4. Дополнительная информация
-   **Состав**: Перечень ингредиентов, входящих в состав продукта.
-   **Аллергены**: Указание потенциальных аллергенов.
-   **Срок годности (дни)**, **Температура хранения**: Условия хранения продукта.
-   **Теги**: Ключевые слова для поиска и фильтрации (например, "веган", "без сахара").

### 5. Настройки отображения
-   **Активен**: Переключатель, определяющий, будет ли товар виден на витрине.
-   **Ингредиент**: Указывает, что данная позиция является не готовым продуктом, а компонентом для других блюд.
-   **Популярный**: Флаг для отметки популярных товаров (может использоваться для специальных витрин или отчетов).
-   **Новый товар**: Флаг для отметки новинок.

После заполнения всех полей пользователь нажимает **"Сохранить"** или **"Создать"**, чтобы применить изменения.
